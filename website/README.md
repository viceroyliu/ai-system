# 明镜见心 · Aimira 官网

产品宣传站点，独立于主应用（`web/`）的纯静态项目，零构建依赖。

## 内容

- `index.html` — 单页落地页（Hero / 核心能力 / AI 视角 / 工作流 / 隐私 / FAQ / CTA / 页脚）
- `styles.css` — 全部样式，沿用主应用的靛蓝 + 粉色设计系统
- `app.js` — 滚动渐入、导航栏吸附、移动端菜单等交互

## 本地预览

任选其一：

```bash
# 方式 1：直接用浏览器打开
open index.html

# 方式 2：起一个静态服务器（推荐，路径更干净）
cd website && python3 -m http.server 4000
# 然后访问 http://localhost:4000
```

## 说明

- 页面中所有「进入应用 / 免费开始」按钮指向主应用入口 `http://localhost:3000`，
  部署到线上时把这些链接替换为正式域名即可。
- 当前仅为宣传官网；登录鉴权 / 多用户能力尚未实现（规划中）。

## 部署

纯静态站点，可直接托管到任意静态平台（Vercel / Netlify / GitHub Pages / 对象存储 + CDN）。
将整个 `website/` 目录作为站点根上传即可。
